## SSH Session

In this example user _richard_ has opened a pseudo terminal on host _Tardis_ and entered
ssh command to connect to host _caliban_. Host _caliban_ prompts for the password to logon
as a local _caliban_ user _richard_ (the password is not echoed). It then prints out a
welcome message, the last login information and a command prompt (in green).
